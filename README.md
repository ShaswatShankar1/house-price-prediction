# 🏠 House Price Prediction using Machine Learning

## 📌 Project Overview
This project predicts house prices based on:
- Area (sq ft)
- Number of Bedrooms
- Number of Bathrooms

A Linear Regression model is used to train and predict prices.

## 🛠 Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn

## 📂 Dataset
A small housing dataset containing:
- Area
- Bedrooms
- Bathrooms
- Price

## ⚙ How to Run
1. Clone the repository  
2. Install dependencies
